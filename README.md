# Clinical Trials Analytics — Precision Oncology

Data analytics pipeline for exploring and analyzing precision oncology clinical trial data.

🐍 Python • 🗄️ SQL • 🐼 Pandas • 📊 Power BI

## Dataset

The complete clinical trial datasets are hosted on Kaggle because of their large file sizes.

The Kaggle dataset contains:

- `trials_master_UNCLEANED.csv` — Original collected dataset
- `trials_master_CLEANED.csv` — Cleaned and processed dataset
- `trials_master_ANNOTATED.csv` — Bioinformatics-annotated dataset with biomarker and genetic alteration information

### Full Dataset
